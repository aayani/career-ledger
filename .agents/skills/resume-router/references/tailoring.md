# Resume Tailoring

## Requirement map

For a vacancy or role family:

1. Extract must-haves, nice-to-haves, keywords, seniority, scope, and stated problem.
2. Map each requirement to employment, education, project, or skill IDs as **Direct**, **Transferable**, **Gap**, or **Unclear**.
3. Use source terminology only when evidence supports it; distinguish missing keywords from missing capabilities.
4. Select at most five priorities and report genuine gaps. Offer `career-ledger` for missing user facts.

Without a vacancy, use labelled role-family assumptions or request a representative listing. Never invent a company.

## Emphasis rules for every scope

- Emphasize current and recent roles unless older evidence is stronger.
- Give each role a distinct purpose; avoid repeated claims.
- Keep the summary short and `Skills` evidence-backed, specific, and recent.
- Preserve recorded employers, titles, and dates exactly.

## Output structure

- Place linked projects under matching experience without duplicate claims.
- Add up to five relevant independent projects under `Personal Projects`, then `Skills`.
- Use recorded STAR facts and technologies only; reconcile technologies into `Skills`.
